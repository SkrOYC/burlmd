# Glossary: Ubiquitous Language

| Term | Definition | Do Not Use |
| :--- | :--- | :--- |
| Note | A single conceptual document created by the user, representing a unit of knowledge. | Page, Document, File |
| Directory | A hierarchical container used to logically group and organize Notes. | Folder, Collection |
| Link | A lateral connection between two Notes, forming the knowledge graph structure. | Backlink, Reference, Tag |
| Workspace | The root container holding all Notes and Directories, backed by a remote repository. | Vault, Brain, Repo, Database |
| Suggestion | An intuitive UI paradigm for resolving concurrent edit conflicts without exposing diffs. | Conflict, Merge, Diff, Fork |
| Block | A discrete structural element within a Note (e.g., paragraph, list item) during editing. | Node, Segment |
