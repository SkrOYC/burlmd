# Floating formatting toolbar

**Context:** CAP-EDIT-07 proposed a pointer-driven formatting toolbar after text selection.

**Decision:** Deferred.

**Reason:** Keyboard shortcuts and direct Markdown editing serve the primary Writer. The toolbar doesn't block feature completeness.

**Consequences:** Remove CAP-EDIT-07 from the active capability set. Reopening requires a Product Requirements Evolution pass based on observed pointer-driven demand.
